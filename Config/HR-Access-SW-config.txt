Enterprise Multi-Site Network

Device Name : HR-Access-Switch
Device Type : Cisco Catalyst 2960

Role
------------------------------------------------------------
• HR Department Access Switch
• Provides Layer 2 Connectivity
• VLAN Segmentation
• IEEE 802.1Q Trunking
• Switch Management using VLAN 60

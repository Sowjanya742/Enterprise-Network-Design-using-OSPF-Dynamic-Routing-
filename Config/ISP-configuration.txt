============================================================
Enterprise Multi-Site Network
============================================================

Device Name : ISP
Device Type : Cisco 2911 Router

Role
------------------------------------------------------------
• Simulates the Internet Service Provider (ISP)
• Connects the Internet Router to the Enterprise Edge Router
• Acts as the WAN Transit Router
• Forwards traffic between the Internet and Enterprise Network

============================================================
Configuration
============================================================

version 15.1

no service timestamps log datetime msec
no service timestamps debug datetime msec
no service password-encryption

hostname ISP

!
! Enable secret removed for public GitHub repository
!

ip cef
no ipv6 cef

!
!===========================================================
! Interfaces
!===========================================================
!

interface GigabitEthernet0/0
 description Link-to-Internet
 ip address 1.1.1.2 255.255.255.252
 duplex auto
 speed auto

interface GigabitEthernet0/1
 description Link-to-Enterprise-Edge
 ip address 2.2.2.1 255.255.255.252
 duplex auto
 speed auto

interface GigabitEthernet0/2
 no ip address
 shutdown

interface Vlan1
 no ip address
 shutdown

!
!===========================================================
! Routing
!===========================================================
!

ip classless

!
! No dynamic routing protocol is configured.
! The ISP simply forwards packets between the
! Internet Router and Enterprise Edge Router.
!

ip flow-export version 9

!
!===========================================================
! Console & Remote Access
!===========================================================
!

line con 0

line aux 0

line vty 0 4
 login

end

============================================================
End of Configuration
